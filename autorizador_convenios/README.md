# Autorizador de Convênios

## Scripts disponíveis

- INAS.js
- ASSEFAZ.js
- GEAP.js
- CASSI.js

## Utilização

1. Acesse o portal do convênio.
2. Pressione F12.
3. Abra a aba **Console**.

### Liberação da colagem no Console

4. Se estiver usando o Google Chrome, digite:

```text
allow pasting
```

e pressione Enter.

5. Se estiver usando o Microsoft Edge, digite:

```text
permitir colagem
```

e pressione Enter.

> **Observação:** digite o comando sem aspas.

### Execução do script

6. Cole o conteúdo do script.
7. Pressione Enter.
